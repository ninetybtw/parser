# leadgen

Полуавтоматический поиск клиентов по нише: ВКонтакте, Telegram-каналы, биржи
фриланса → дедупликация → персональный черновик предложения (Claude) → макет-превью
сайта из логотипа и прайса → карточка, где отправку делаешь **сам, вручную**.

Подробная архитектура, лимиты, хранение, подход к макетам и план развития —
в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Быстрый старт

```bash
python -m venv .venv && . .venv/bin/activate
pip install -e ".[dev]"            # + ".[telegram]" для Telegram, ".[screenshots]" для PNG-превью
cp .env.example .env               # заполни ключи и блок «О тебе»
leadgen sources                    # какие источники подключены
leadgen search "ремонт техники" --limit 30
leadgen serve                      # http://127.0.0.1:8000
```

Для PNG-скриншотов макетов дополнительно: `playwright install chromium`.
Для Telegram один раз: `leadgen tg-login` (код придёт в приложение Telegram).

## Как пользоваться

1. Запусти поиск из интерфейса или командой `leadgen search "<ниша>"`.
   Флаг `--expand` добавляет поисковые фразы из профиля ниши.
2. Открой карточку, прочитай и поправь черновик. При необходимости сгенерируй заново.
3. «Скопировать текст и открыть диалог» копирует текст и открывает диалог на площадке.
   PNG макета скачивается ссылкой под превью, чтобы приложить его к сообщению.
4. Отправь сообщение сам и нажми «Отправлено». «Не писать» навсегда убирает бизнес
   из выдачи.

Без `ANTHROPIC_API_KEY` предложения собираются из шаблонов ниши. Без ключей
источников интерфейс работает, но искать будет негде.

## Структура

```
leadgen/
  sources/      vk.py, telegram.py, rss.py — по модулю на площадку
  db.py         SQLite, дедупликация по идентичностям, стоп-лист
  niches.py     профили ниш: фразы поиска, «боли», идеи сайта и бота
  offer.py      генерация предложения (Claude + шаблонный фолбэк)
  mockup/       палитра из логотипа, прайс, HTML-шаблон, скриншот
  pipeline.py   поиск → дедупликация → макет → предложение
  web/          FastAPI-интерфейс
tests/          pytest, без сети
```
